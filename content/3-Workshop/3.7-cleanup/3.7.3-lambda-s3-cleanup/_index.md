# 3.7.3. Cleaning Up AWS Lambda & Amazon S3 Buckets

Next, the procedure will proceed to decommission the Serverless services and the static storage repositories for both the Frontend and Media components.

### Step 1: Deleting the AWS Lambda Function

1. Access the **Lambda** service on the AWS Management Console.
2. In the left navigation pane, select **Functions**.
3. Check the `Eshop-Image-Resizer` function that was provisioned in the previous sections.
4. Click the **Actions** menu and select **Delete**. 
5. Enter the keyword `delete` into the confirmation box and click the **Delete** button to execute.

### Step 2: Emptying and Deleting Amazon S3 Buckets

Due to Amazon S3's built-in protection mechanism, a Bucket cannot be deleted if it still contains objects (data). Therefore, emptying the Bucket is a mandatory prerequisite step.

1. Access the **S3** service.
2. Locate and access the Frontend Bucket (e.g., `eshop-frontend-...`).
3. Select all contained files (`index.html`, `js/` directory, etc.), then click the **Delete** button. Enter the phrase `permanently delete` to confirm emptying the Bucket.
4. Return to the Buckets list, select the recently emptied `eshop-frontend-...` Bucket, and click the **Delete** button to remove it completely from the account.
5. Repeat steps 2 through 4 for the Media storage Bucket (`eshop-media-...`). Ensure all data is deleted, including the `resized/` directory previously generated by the Lambda function.

### Step 3: Deleting CloudWatch Logs (Optional)

Although this operation is not mandatory and the cost of retaining logs is minimal, cleaning up logs helps maintain a well-organized and optimized resource environment.
1. Access the **CloudWatch** service, and from the navigation pane, select **Logs** -> **Log groups**.
2. Search for the log group named `/aws/lambda/Eshop-Image-Resizer`.
3. Select this log group, click **Actions** -> **Delete log group**, and confirm to finalize.

*(Note: At this stage, only the network infrastructure skeleton remains. The subsequent and final section will guide the complete teardown of this network architecture).*
